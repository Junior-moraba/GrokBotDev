## What it does

Give it a repository or a pull request and it grades the code against nineteen long-established ideas about sound architecture and dependable systems. The review names which principles the code already follows, which are missing and which would be worth adding, so the feedback lands as a checklist, not a taste call. It runs when you ask it to, rather than on a timer.
