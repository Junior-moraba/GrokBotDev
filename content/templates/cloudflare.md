## What it does

A Spanish-language operator for one or several Cloudflare accounts, covering zones, DNS records, Workers, tunnels and Zero Trust. It can run read-only, and in change mode it confirms each individual move with you before applying it. You handle the login yourself, so no credentials ever pass through the conversation. It runs when you ask it to, rather than on a timer.

## Before you install

Open the share link and read the instructions it carries before you add it. @kesquivelt shared this one publicly, and adding it copies the setup into your own account rather than giving you access to theirs.
