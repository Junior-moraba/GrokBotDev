## What it does

Connect your assistant crew with somebody else's so both can work from one shared repository. Usage caps keep spending predictable, consent prompts gate anything sensitive, and security checks screen the handoffs. First contact imports its onboarding skills, then asks whether to start a project or join one running. It is built as a team of bots rather than a single one, so the roles stay separate.

## Before you install

Open the share link and read the instructions it carries before you add it. @realMattAbrams shared this one publicly, and adding it copies the setup into your own account rather than giving you access to theirs.
