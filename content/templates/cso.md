## What it does

Secrets end up in code all the time, and this one goes looking: it sweeps your files and repositories for API keys that should never have landed there. When exposure turns up, rotation is walked through step by step for the affected Cloudflare, AWS or 1Password credentials, so the leak stops mattering fast. It runs when you ask it to, rather than on a timer.
