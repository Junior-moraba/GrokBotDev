## What it does

Point it at a GitHub repository and it returns in about two minutes with a prioritized list: which packages are vulnerable, the exact commands to upgrade them, and any committed credentials, masked, with rotation steps. It only reads, changing nothing, and overnight alerts fire just when a new problem shows up. It runs when you ask it to, rather than on a timer.
