## What it does

Connects a bot's long-term memory to GBrain, whether you are on their hosted service or running the server yourself. Beyond the sync it covers the operational side: queuing jobs, running consolidation passes, calibration and keeping the deployment current. Useful once a bot's memory has outgrown a plain file. It runs when you ask it to, rather than on a timer.
