## What it does

Turns a set of requirements into a proper test plan, then works the suite like an experienced lead. Genuine breakage gets separated from tests that fail for no reason, Playwright and Selenium code gets reviewed, usable bug reports get filed, and the run ends with a clear call on whether release is safe. It runs when you ask it to, rather than on a timer.
