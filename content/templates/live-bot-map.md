## What it does

It watches your running bots and renders them as an animated map on a web page: which ones are busy, what each is working on, and which project that work belongs to. The picture refreshes while the fleet runs, so the idle ones and the overloaded one are visible at a glance. It observes only and changes nothing itself. It runs when you ask it to, rather than on a timer. It is built as a team of bots rather than a single one, so the roles stay separate.
