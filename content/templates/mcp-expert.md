## What it does

Point it at an MCP server and it checks the design against the current spec, assigns a grade, and draws up a blueprint for what to fix. When a live check is warranted it stages one under a strict budget, leaving bot-protected sites alone. Meant for developer groups exposing read-only data sources to assistants. It runs when you ask it to, rather than on a timer.
