## What it does

Links a chat bot to T3 Code over its MCP server so you can open coding threads without leaving the conversation. It starts sessions, steers them with follow-up instructions, watches progress, and passes results or questions back to you or to other bots in your fleet. Useful when several coding runs need one supervisor. It runs when you ask it to, rather than on a timer. It is built as a team of bots rather than a single one, so the roles stay separate.
