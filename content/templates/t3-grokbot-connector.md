## What it does

Agent sessions in terminal coding tools no longer need you watching the window. When a Claude Code, Codex or T3 Code run completes, hangs or dies, one short notification arrives saying what happened and what is waiting on you. It hooks into an open-source webhook bridge, so the wiring stays visible and self-hosted.
