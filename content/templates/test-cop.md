## What it does

It reads a pull request for the quiet ways a suite gets hollowed out: cases skipped, assertions loosened, configuration narrowed, CI rules softened. Each finding feeds one verdict, clean or suspect or weakened, so reviewers can triage at a glance. It catches changes that make a suite greener while checking less. It runs when you ask it to, rather than on a timer.
